# Mímir 0.06

- Your PC's own model comes first. Claude is only an option now: there is no install button in the side list, the PC's model is the normal choice, and Settings › Models says plainly that online answers go to Anthropic.
- Literal answers: the built-in rules for every chat now say to answer exactly what you ask, in the subject's own terms, with no other views, warnings or advice unless you ask for them. Rules you wrote yourself are kept.
- Hidden details are removed from files, not just pictures. PDFs, Word, Excel, PowerPoint and LibreOffice files, recordings, books and zips lose their author, company, dates, editing history, location and comments before a model reads them. A file that can't be cleaned is never sent to an online model; a short line under it says so.
- Running on your PC: the phone shows what is running on your PC (Your PC, "● N running"), including tasks started in a terminal or another app, and Stop works on those too. Notes from the PC show as a small dim line, and a task you stopped stays stopped.
- Project task messages on the phone now have Copy, Listen, Share, Try again and Edit.
- Answers read better: tables, code with a Copy button, line breaks and lists.
- Calmer and plainer on both sides: the PC opens with "Hi, I'm Mímir." and a chat, the meters panel opens only while something runs, empty sections stay hidden, and developer words are gone. On the phone: "Go ahead without asking" instead of slang, no "Recommended" on online services, "Uncensored" as the one name for unfiltered models, Wikipedia and Grokipedia named where you choose them, and Paste for the pairing code.
- Private by default: the PC no longer keeps a 14-day log of your chats unless you switch it on, and an online model is never told the chat is private.
- Fixes: alerts work right after pairing, a missing project folder is refused with a plain line, and a test leftover that could pile up temporary files is gone.

Known not working yet: attaching files from the phone inside a project task (next version); Edit in a task sends your edited words as a new message and doesn't yet replace the later replies; motion on older phones is not smooth yet (on a 2017 test phone, 22% of frames were late while scrolling a chat; the goal is under 5%); sharing a table sends it as plain lines.
